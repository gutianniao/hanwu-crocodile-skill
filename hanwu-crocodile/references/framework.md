# 投资框架

## 周期、价值、复利

1. **周期。** 先问导致机会的供需失衡如何形成、怎样消失。价格好了，产能会进来。过剩持续一段时间，高成本产能才可能退出。区分临时检修与永久退出、去库存与新增需求，以及行业底与公司的财务底。不同品种有不同的产能时间。W000、W091、W096、W098。
2. **价值。** 买股票是在买企业的部分所有权。先认清企业持有什么资产、卖什么产品、谁付钱、利润受哪个价格或成本驱动。陈泽鑫偏好自己熟悉的周期资源和商品，选股文章强调国资控股、主业集中、经营方式简单、产品难替代及盈利弹性。判断主营资产价值之后再问市场价格。W035–W040、S001、S002。
3. **复利。** 持续做少数能理解的事，留出活过错误的余地。复盘时间尺度要和投入匹配，日内波动无法单独检验多年供需逻辑。W000、W093、S003。

## 把思想变成动作

| 遇到什么 | 先做什么 | 复审时找什么 |
| --- | --- | --- |
| 行业越来越差 | 画近年的产能、开工、库存和价格，查高成本供给是否退出 | 补贴、有行业外订单或存在替代品时，持续亏损未必导致有效出清。W091、W096 |
| 股价到了低位 | 拆产品、产销量、售价和成本，查同口径年报，每种情景都算价值 | 净资产的实际质量、亏损能否持续、买入数量是否有流动性。S002、S004 |
| 决定要不要持有 | 写出最初买入的理由、预期兑现时间和证伪条件 | 价格波动和经营变化各自标清。出现新事实再修改判断。W051、S003 |
| 有机会开始兑现 | 对照价值区间、供给反馈和市场预期，按事先的计划检视退出 | 不把某次涨停数、换手率或最高成交价当普适阈值。W049、S004 |
| 要集中资金 | 算总资金、流动性、回撤和公司资产负债，留生存冗余 | 研究集中和持仓集中是不同决策。杠杆、现金需求或冲击成本可能迫使提前退出。W043、W054、S005 |

## 用于新问题

先列主要矛盾和一条可能的反证。比如，投资化工企业时，价格上涨只是待检事实。看价差，要同时核对原料成本、单位消耗、实际销量与产品结构。跨到人生决策时，同样先问什么条件最重要、会如何随时间变化，再看最坏结果能否承担。把自己的成本价、已发生的盈亏和当下证据分开记。W088、W089。
