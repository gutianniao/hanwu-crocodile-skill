# 公开案例、品质与书目

| 案例 | 可迁移的动作 | 证据与边界 |
| --- | --- | --- |
| 孜然高价后引来扩种 | 看到涨价先查跟进产能要多久，列出投产后库存与需求情景 | 《股海无疆》的文学情节，适合作为类比。W008 |
| 啤酒花滞销后库存重新上市 | 判断供需拐点时，把可能重新进入市场的库存也算进去 | 小说写到干花库存被重新取出，适合作为机制例子。W009 |
| 第一笔股票交易碰到急跌 | 复盘把判断、订单执行和运气分开，保留当时的限价、成交与信息 | 小说情节，逐字引用回原著。W004 |
| 研究资源股和房产 | 记录分析期限、持有期限和复审证据，检查三者是否相容 | 本人用不同资产的时间尺度举例。S003 |
| 最低价只短暂出现在盘面 | 查同价位可成交量、成交窗口和滑点；规模较大时按可实现平均成本估算 | 本人结合历史分时和换手举例，证据是特定事件。S004 |
| 早年短线探索后改变研究方向 | 核对成功是否可复制，事后写下当时错误归因和下一次验证方法 | 本人回忆，具体收益不能当成外部审计数据。S006 |
| 多年记录经验与教训 | 写下当时的事实、选择、结果和下次会触发行动的条件 | 作者自述随身记小本子。S007 |

**可以学的品质。** 对自己诚实，可以从写下一条当时漏看的反证开始。耐心体现在等有证据的过程，每隔一段时间复核一个可观察变量。实证习惯体现在估值之前把财报和成交条件查清。处理人际关系时，他主张账目和规则清楚，给别人留体面与回旋空间。这最后一项的直接证据是他公开表达的原则。S002、S004、S007、W082、W088。

## 书单按证据使用

- **明确推荐。** 霍华德·马克斯《投资最重要的事》。他谈及风险、周期、标的和企业质量。S008。
- **明确说明受其影响。** 马克思《资本论》。他把生产资料、资产和分配作为分析起点，分享过将书中角色代入自己的实际问题的读法。S009、S010。
- **主动购买和推荐学习。** 巴菲特历年致股东的信与股东大会问答。S011。
- **出现在进阶书单。** 《世界上最简单的会计书》《股市真规则》《聪明的投资者》等可以按原书单附图核对。书单收录只支持「推荐范围」，逐本阅读记录另找本人出处。S012。

学习顺序可从财报核心数字开始，进到行业结构和上市公司比较，再用历史和宏观扩展。每读一章选一个能用数据或案例验证的问题。W057、W058、S006。
